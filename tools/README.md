# Локальная панель управления воркером

`console.html` — одностраничная панель для запуска `generate` и `edit`
на RunPod endpoint: промпт, входные картинки, выбор LoRA, параметры,
результат и лог.

## Запуск

Откройте файл в браузере. Двойного клика в проводнике достаточно:

```
tools/console.html
```

Если браузер заблокирует запросы с `file://`, поднимите локальный сервер
из корня репозитория и откройте <http://localhost:8000/tools/console.html>:

```bash
python -m http.server 8000
```

Затем нажмите **Доступ**, вставьте RunPod API key и укажите endpoint ID.

## Про ключ

Ключ хранится в `localStorage` вашего браузера и отправляется напрямую в
`api.runpod.ai`. В файл он не попадает, в репозиторий тоже. Кнопка
**Забыть ключ** стирает его из браузера.

## Почему не artifact

Песочница артефактов Claude запрещает `fetch` на внешние хосты через CSP,
поэтому опубликованная страница не может обращаться к RunPod. Локальный
файл этого ограничения не имеет: RunPod отдаёт
`access-control-allow-origin: *`, и браузер пропускает запрос.
